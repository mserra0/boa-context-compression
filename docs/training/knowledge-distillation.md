# Knowledge Distillation

## Objective

The compressor is trained to **match the output distribution of the frozen LLM** running on the full uncompressed prompt. We do not train the compressor to produce exact surface token predictions — we train it to produce soft prompt vectors that, when fed into the frozen LLM, yield a next-token probability distribution closely matching the teacher's distribution.

This is **distributional alignment**, not sequence-level token matching. It allows the student to generalize across paraphrases, reasoning paths, and different phrasings.

---

## Teacher Generation and Student Forward

### Teacher Generation

The teacher is the **same frozen LLM** used for student inference (e.g. Qwen2.5). Given the full uncompressed prompt (`llm_inputs`):

```python
generated_ids, teacher_logits = model.generate_teacher(llm_inputs)
# generated_ids:   [B, G]      — tokens generated by teacher
# teacher_logits:  [B, G, V]   — raw logits captured at each generation step
```

The teacher executes `llm.generate(..., output_scores=True)` to capture both the generated continuation tokens and the unnormalized logits for all $G$ steps.

### Student Forward Pass

The student receives compressed soft prompts concatenated with the **teacher-generated tokens** (not ground-truth reference text):

```python
combined_embeds = torch.cat([soft_prompts, embed(generated_ids)], dim=1)
# [B, C+G, H_llm]

student_logits = model.generate_student(combined_embeds, attention_mask, compressed_len)
# [B, G, V]
```

The student predicts the next token at each step $g \in [0, G-1]$ given prior teacher tokens as context. Causal shift alignment ensures that the hidden state at position $C + i - 1$ predicts token $G_i$.

## Valid Position Masking (`valid_positions_mask`)

After the teacher emits an end-of-sequence (EOS) token, trailing positions in `generated_ids` contain padding tokens. Positions after the EOS carry no valid training signal and must be masked out.

However, the masking is **EOS-aware, not pad-aware**. The function `valid_positions_mask` (`src/losses.py`) keeps every token up to **AND INCLUDING** the first EOS token in each row:

```python
# src/losses.py
def valid_positions_mask(generated_ids: torch.Tensor, eos_token_ids) -> torch.Tensor:
    if isinstance(eos_token_ids, int):
        eos_token_ids = [eos_token_ids]
    eos = torch.tensor(list(eos_token_ids), device=generated_ids.device)
    is_eos = (generated_ids.unsqueeze(-1) == eos).any(-1)   # [B, G]
    eos_seen = is_eos.cumsum(dim=1)                          # [B, G], inclusive
    # before the first eos (eos_seen == 0), plus the first eos itself (is_eos & ==1).
    return (eos_seen == 0) | (is_eos & (eos_seen == 1))
```

### Key Technical Details

1. **Multi-EOS Support:** `eos_token_ids` can be an `int` or an iterable (e.g. Qwen2.5 uses multiple EOS IDs: `<|endoftext|>` `151643` and `<|im_end|>` `151645`).
2. **EOS Detection (`is_eos`):** `(generated_ids.unsqueeze(-1) == eos).any(-1)` creates a boolean mask of shape `[B, G]` indicating whether a token matches *any* valid EOS token.
3. **Inclusive Cumsum (`eos_seen`):** `is_eos.cumsum(dim=1)` computes an inclusive running count of EOS tokens observed in each row.
4. **Mask Logic:** `(eos_seen == 0) | (is_eos & (eos_seen == 1))` evaluates to `True` for:
   - All positions before the first EOS (`eos_seen == 0`).
   - The first EOS token itself (`is_eos & (eos_seen == 1)`).
   - All subsequent post-EOS padding tokens evaluate to `False`.

### Why EOS-Aware Masking is Critical

On models like Qwen, the pad token ID (`<|endoftext|>`, `151643`) is identical to one of its valid EOS IDs. A naive `generated_ids != pad_id` mask would incorrectly drop the **first EOS token** whenever the teacher terminates with `<|endoftext|>`.

The first EOS token is essential training signal: the student must learn when to stop generating. Trailing tokens beyond the first EOS are uninformative padding noise. Rows where the teacher did not emit an EOS (e.g., reaching `max_new_tokens`) keep all $G$ positions.

## KL Divergence Loss (`kl_loss`)

`kl_loss` (`src/losses.py`) calculates the temperature-scaled KL divergence between student and teacher distributions over supervised positions:

```python
# src/losses.py
valid = valid_positions_mask(generated_ids, eos_token_ids).to(student_logits.dtype)  # [B, G]
per_tok_kl = F.kl_div(
    F.log_softmax(student_logits / temperature, dim=-1),
    F.softmax(teacher_logits / temperature, dim=-1),
    reduction='none',
).sum(-1)  # [B, G]
return (per_tok_kl * valid).sum() / valid.sum().clamp_min(1.0) * (temperature ** 2)
```

### Formula & Implementation Breakdown

1. **Log-Softmax & Softmax:**
   - Student log probabilities: $\log \sigma(\mathbf{z}_s / T)$
   - Teacher probabilities: $\sigma(\mathbf{z}_t / T)$
2. **Per-Token Reduction (`reduction='none'`):**
   `F.kl_div(..., reduction='none')` preserves the full `[B, G, V]` loss matrix. Calling `.sum(-1)` sums over the vocabulary dimension $V$, yielding a per-token KL tensor `[B, G]`.
3. **Masked Token Mean:**
   `(per_tok_kl * valid).sum() / valid.sum().clamp_min(1.0)` calculates the mean KL over supervised tokens only. `clamp_min(1.0)` protects against division by zero if all tokens in a batch are invalid.
4. **$T^2$ Gradient Scaling:**
   Multiplying by $T^2$ compensates for the $1/T^2$ reduction in gradient magnitude caused by temperature softening (Hinton et al., 2015), keeping gradient scales consistent across different temperatures.

## Loss Variants in `src/losses.py`

`src/losses.py` defines three distinct loss functions for distillation and pretraining:

### 1. Standard Token-Uniform KL (`kl_loss`)

```python
loss = kl_loss(student_logits, teacher_logits, generated_ids, temperature, eos_token_ids)
```

- **Usage:** Standard KD objective (`loss_type: "kl"`).
- **Behavior:** Every valid token position contributes equally to the average loss.

---

### 2. Confidence-Weighted KL (`confidence_weighted_kl_loss`)

```python
loss = confidence_weighted_kl_loss(
    student_logits, teacher_logits, generated_ids, temperature, eos_token_ids, mode="max_prob"
)
```

- **Usage:** Selective distillation (`loss_type: "confidence_kl"`).
- **Motivation:** Teacher predictions at low-entropy positions (factual names, dates, specific tokens) carry rich information, whereas high-entropy positions (generic punctuation, filler words) carry low signal. Weighting by teacher confidence focuses gradients on high-certainty tokens.
- **Modes:**
  - **`mode="max_prob"`:**
    $$\text{weight}_{b,g} = \max_v \sigma(\mathbf{z}_{t,b,g} / T)_v$$
    Evaluates top token probability mass in range $[1/V, 1.0]$. Simple and numerically stable.
  - **`mode="neg_entropy"`:**
    $$\text{entropy}_{b,g} = -\sum_v p_v \log(p_v + 1e-9), \quad \text{weight}_{b,g} = \frac{1.0}{\text{entropy}_{b,g} + 1e-6}$$
    Inverts Shannon entropy of the softened teacher distribution. Strongly down-weights uncertain or ambiguous token positions.
- **Normalization:**
  Weights are zeroed at invalid positions (`weights = weights * valid`) and normalized by weight sum:
  $$\text{Loss} = \frac{\sum_{b,g} \text{KL}_{b,g} \cdot \text{weight}_{b,g}}{\sum_{b,g} \text{weight}_{b,g} + 1e-9} \times T^2$$

---

### 3. Continuation Pretraining Cross-Entropy (`lm_ce_loss`)

```python
loss = lm_ce_loss(student_logits, target_ids, target_mask)
```

- **Usage:** Language modeling pretraining objective on document continuation datasets (e.g. FineWeb-EDU).
- **Signature & Behavior:**
  ```python
  # src/losses.py
  def lm_ce_loss(student_logits, target_ids, target_mask):
      B, G, V = student_logits.shape
      mask = target_mask.to(student_logits.dtype)
      per_tok = F.cross_entropy(
          student_logits.reshape(-1, V),
          target_ids.reshape(-1),
          reduction="none",
      ).reshape(B, G)
      return (per_tok * mask).sum() / mask.sum().clamp_min(1.0)
  ```
  Computes unreduced cross-entropy between student logits and target token IDs, masks out padding using `target_mask`, and averages across real target positions.
